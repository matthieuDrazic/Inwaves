# Inwaves — V1

PWA de météo surf pour **Longchamp** et **Grande Plage**, Saint-Lunaire.

## Publication
GitHub > Settings > Pages > Deploy from a branch > **main / root**. Adresse prévue : https://matthieudrazic.github.io/Inwaves/

## Fonctionnalités
- Prévisions horaires gratuites Open-Meteo Marine et Weather.
- Comparaison exploratoire des spots (score heuristique, **non validé**).
- Animation 2D pédagogique et carte schématique de la houle.
- Fiches descriptives des plages et extrema de niveau marin modélisé.
- Interface mobile installable depuis Safari > Partager > Sur l'écran d'accueil.

## Limites
Les données offshore sont communes aux deux plages : aucune modélisation de vagues à la côte, de bathymétrie, de courants, ni correction des modèles par bouées ou webcams. Les scores et les recommandations sont indicatifs. Les extrema de niveau marin ne remplacent pas des horaires officiels du SHOM. Vérifier les conditions réelles et la sécurité sur place.

Sources : https://open-meteo.com/en/docs/marine-weather-api ; https://open-meteo.com/en/docs ; https://www.openstreetmap.org/copyright.
